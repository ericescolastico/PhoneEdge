# PhoneEdge

Fork do [scrcpy](https://github.com/Genymobile/scrcpy) (Apache 2.0) que vai permitir usar o mouse e o teclado do PC
Windows no celular Android ao empurrar o cursor pela borda do monitor ("mouse sem bordas").

Protótipo em desenvolvimento. Estado atual (Fase 1): cliente enxuto, sem janela, que conecta por ADB e cria
um mouse e um teclado virtuais (UHID) no celular. Veja `docs/analise.md` e `docs/removido.md`.
